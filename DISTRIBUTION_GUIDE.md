## 🚀 Installation Instructions

### **Mac Installation:**
1. Download the appropriate `.dmg` file for your Mac
2. Double-click the `.dmg` file to open it
3. Drag the "Laptop Inventory Tracker" app to your Applications folder
4. Launch the app from Applications or Spotlight search
5. **First time**: You may need to right-click and select "Open" to bypass security warnings

### **Windows Installation:**
1. Download `Laptop Inventory Tracker Setup 1.0.0.exe`
2. Double-click the installer to run it
3. Follow the installation wizard
4. Choose installation directory (default is recommended)
5. The installer will create desktop and start menu shortcuts
6. Launch the app from desktop shortcut or start menu

## 🆘 Troubleshooting

### **Common Issues:**

#### **Mac - "App can't be opened because it's from an unidentified developer"**
1. Right-click the app
2. Select "Open"
3. Click "Open" in the dialog
4. The app will be added to your trusted applications

#### **Windows - Antivirus Warning**
1. Some antivirus software may flag the installer
2. This is normal for unsigned applications
3. Add an exception or temporarily disable antivirus during installation

#### **Login Issues**
- Ensure you're using your @whitehatgaming.com email
- Check your internet connection
- Contact IT if you need password reset

#### **App Won't Start**
1. Restart your computer
2. Try running as administrator (Windows)
3. Check if another instance is already running
